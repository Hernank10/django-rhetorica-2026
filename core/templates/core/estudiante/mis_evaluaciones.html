Sistema de evaluaciones

Cómo funcionan las evaluaciones
Auto-evaluacion

Las evaluaciones son pruebas autocorregidas que cierran cada modulo de un curso. Puedes intentarlas varias veces: el sistema guarda tu mejor puntaje y el ultimo intento. Aprobarlas refuerza las tecnicas y suma puntos para tus logros.

Pendientes

Evaluaciones de cursos en los que estas inscrito y aun no has hecho.

Completadas

Evaluaciones que ya has intentado al menos una vez.

Mejor puntaje

Se guarda el mejor resultado de todos tus intentos. Mejorable.

Como aprovechar las evaluaciones:

  1. Estudia el modulo primero: lee las lecciones y practica con los ejercicios.
  2. Haz la evaluacion: responde sin miedo. Puedes repetirla si no te convence el resultado.
  3. Revisa los errores: cada fallo te dice que concepto repasar.
  4. Vuelve a intentarla: si mejoras, el "mejor puntaje" se actualiza.
  5. Aprobarla suma: al superar el umbral, la evaluacion cuenta para los logros del curso.
No tienes evaluaciones pendientes?

Eso significa que no estas inscrito en ningun curso con evaluaciones disponibles, o ya las has completado todas. Puedes explorar el catalogo de cursos para inscribirte, o practicar con la biblioteca de ejercicios.
