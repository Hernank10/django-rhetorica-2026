{% extends 'base.html' %} {% load static %} {% block content %} Algoritmo de repeticion espaciada Cómo funciona SM-2 SuperMemo 2 SM-2 es un algoritmo de repeticion espaciada: decide cuando volver a mostrarte cada flashcard segun lo bien que la recuerdes. No es magia: es una formula que ajusta dos variables. Facilidad (EF) Cuanto te cuesta esta carta (1.3 a 2.5). Sube si aciertas, baja si fallas. Intervalo (I) Días hasta la proxima revisión. Se multiplica por la facilidad cada vez que aciertas. El flujo de cada repaso: Frente: ves el concepto y tratas de recordarlo. Verificar: pulsas "verificar" para ver la respuesta detras. Calificar: evaluas tu desempeno honestamente (No / Casi / Si). Sistema calcula: nueva facilidad + nuevo intervalo + proxima fecha. Proxima revisión: la carta reaparece cuando toca. Regla de oro: calificate con honestidad. Si dices "la sabia" sin saberla, el intervalo se alarga demasiado y la olvidas. Si dices "no la sabia" sabiendola, la carta aparece demasiado pronto y pierdes tiempo. SM-2 se optimiza con calificaciones honestas, no optimistas. Una sesión de SRS ideal dura 10-20 minutos. Si tienes 50+ pendientes, haz tandas de 20 y vuelve mas tarde. La constancia diaria importa mas que las sesiones maratonianas.
