{% extends 'base.html' %} {% load static %} {% block content %} Herramienta de análisis Qué es el registro lingüístico Balance formal / coloquial El registro es el nivel de formalidad del lenguaje segun el contexto y la relacion entre hablantes. Una misma idea puede expresarse en distintos registros sin cambiar su significado. Esta herramienta detecta el registro de un texto y evalua tu paráfrasis. Espectro de registro: Muy formal Formal Neutro Coloquial Muy coloquial Usted Tú Vos Ché Marcadores que cambian el registro: Lexico Vehiculo / coche / carro / auto Pronombres Usted / tú / vos / sumerce Verbos Posee / tiene / tiene / hay Conectores Sin embargo / pero / aunque Como interpretar el balance: Balance equilibrado: paráfrasis correcta (mismo nivel de formalidad). Desplazamiento leve: cambio de registro controlado (util para practicar). Desplazamiento fuerte: cambio radical de registro (cuidado con el significado). El registro no es "mejor" o "peor": es adecuado o inadecuado al contexto. Un texto formal en una conversacion informal suena rigido; un texto coloquial en un informe académico suena poco profesional.
