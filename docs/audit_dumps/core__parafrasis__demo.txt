{% extends 'base.html' %} {% load static %} {% block content %} Herramienta de análisis Qué es una paráfrasis Similitud · Transformacion Una paráfrasis reformula un texto manteniendo su significado. No es copiar ni resumir: es transformar la estructura sin alterar el contenido. Esta herramienta compara el original con tu versión y mide la similitud. Tipos de transformacion: Activa → Pasiva Juan lee el libro → El libro es leido por Juan Pasiva → Activa El libro fue escrito por Cortazar → Cortazar escribio el libro Directa → Indirecta Ella dijo: "Voy a venir" → Ella dijo que vendria Sinonimia estructural El coche es rápido → El automovil corre mucho Como interpretar la similitud: 80-100%: paráfrasis superficial (solo cambiaste palabras). 50-80%: paráfrasis correcta (estructura transformada, contenido intacto). 0-50%: paráfrasis agresiva o posible cambio de significado. Una buena paráfrasis mantiene el significado pero cambia la estructura sintactica. Si la similitud es muy alta, no estas parafraseando: estas sustituyendo palabras.
